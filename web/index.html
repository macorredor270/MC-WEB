Minecraft 1.8 reimplementado desde cero, open source (MIT)

Para ver las texturas originales, elige el 1.8.8.jar de tu instalación de Minecraft. El archivo no sale de tu navegador: se lee aquí y se guarda en IndexedDB para la próxima vez.

¿Dónde está el jar?

Abre una vez Minecraft 1.8.8 en el launcher oficial y búscalo en:
Windows: %APPDATA%\.minecraft\versions\1.8.8\1.8.8.jar
macOS: ~/Library/Application Support/minecraft/versions/1.8.8/1.8.8.jar
Linux: ~/.minecraft/versions/1.8.8/1.8.8.jar
